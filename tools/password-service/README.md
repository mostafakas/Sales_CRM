# خدمة كلمات المرور — مجانية بالكامل

بتشغّل 3 حاجات مش بتنفع من المتصفح لوحده على خطة Firebase المجانية:

- **ريسيت الباسورد من HR:** بيطلّع كلمة مرور مؤقتة، والموظف يختار كلمة جديدة أول ما يدخل.
- **«نسيت كلمة المرور؟»:** بيبعت لينك تغيير كلمة المرور على إيميل الموظف في Outlook.
- **إرسال بيانات الدخول لموظف جديد** على إيميله.

الخدمة بتشتغل على **Google Apps Script**. مش محتاج كارت ولا خطة Blaze، والحد 100 إيميل في اليوم.

> **الإيميلات بتطلع منين؟** Apps Script لازم يشتغل بحساب Google، والأفضل يكون نفس الحساب اللي عامل مشروع Firebase. الإيميلات بتطلع منه باسم «AL MASTER HR»، ولو الموظف ردّ عليها **الرد بيروح على almaster.hr@outlook.com** (متظبط في أول الكود: `REPLY_TO`). الموظفين بيستقبلوا على Outlook عادي.

---

## 1) نزّل مفتاح Firebase (دقيقة واحدة)
1. افتح Firebase Console ← مشروع `almaster-b8c18` ← ⚙️ **Project settings** ← تبويب **Service accounts**.
2. اضغط **Generate new private key** ← **Generate key**. هينزل ملف JSON.
3. ⚠️ الملف ده مفتاح أدمن كامل: **ما ترفعهوش على GitHub** وما تبعتهوش لحد. هتحطه في الخطوة الجاية بس.

## 2) اعمل مشروع Apps Script
1. ادخل على https://script.google.com بحساب Google اللي عامل مشروع Firebase ← **New project**.
2. غيّر اسم المشروع لـ `AL MASTER Password Service`.
3. امسح الكود الموجود في `Code.gs` والصق محتوى ملف `Code.gs` اللي في الفولدر ده.
4. ⚙️ **Project Settings** ← علّم على **Show "appsscript.json" manifest file in editor** ← ارجع للمحرر، افتح `appsscript.json` والصق محتوى الملف اللي هنا.
5. ⚙️ **Project Settings** ← تحت **Script Properties** ← **Add script property**:
   - Property: `SERVICE_ACCOUNT`
   - Value: افتح ملف الـ JSON من الخطوة 1 بـ Notepad، وانسخ **كل** اللي فيه والصقه هنا ← **Save**.
6. ارجع للمحرر ← من القايمة اللي فوق اختار الدالة `setupCheck` ← **Run**.
   - أول مرة هيطلب صلاحيات: **Review permissions** ← اختار حسابك ← **Advanced** ← **Go to AL MASTER Password Service (unsafe)** ← **Allow**. (بيقول unsafe لأنه تطبيقك إنت ومش متراجع من جوجل، وده عادي.)
   - في الـ Execution log لازم يظهر `"firebase": true`.

## 3) انشرها كـ Web app
1. **Deploy** ← **New deployment** ← من ⚙️ جنب Select type اختار **Web app**.
2. Execute as: **Me**. Who has access: **Anyone**.
3. **Deploy** ← انسخ **Web app URL** (بينتهي بـ `/exec`).

## 4) اربطها بالسيستم
1. ادخل السيستم كأدمن ← **الإعدادات ← النظام والترحيل ← الدخول وكلمات المرور**.
2. **دومين الدخول:** الجزء اللي بعد @ في أسماء المستخدمين الحالية. مثلاً لو اليوزر `esraa@almaster.local` اكتب `almaster.local`، وبكده الموظف يقدر يدخل بـ `esraa` بس.
3. **رابط الخدمة:** الصق الرابط من الخطوة 3 ← **حفظ** ← **اختبار الاتصال**. لازم يظهر «شغالة».

## 5) ضيف إيميلات Outlook
- HR: **الموظفين ← تعديل ← البيانات الأساسية ← إيميل الاستعادة (Outlook)**.
- أو كل موظف لنفسه من **حسابي ← إيميل الاستعادة**.

## 6) (اختياري) رجوع الموظف للموقع بعد تغيير كلمة المرور
Firebase Console ← **Authentication ← Settings ← Authorized domains ← Add domain** ← ضيف دومين الموقع (مثلاً `yourname.github.io`).
من غيرها اللينك برضه بيشتغل، بس بعد التغيير الموظف بيفتح الموقع بنفسه.

---

## الاستخدام
- **ريسيت من HR:** الموظفين ← تعديل ← **الصلاحيات** ← **ريسيت الباسورد**. هتظهرلك كلمة مرور مؤقتة، ولو علّمت «وابعته على إيميل الاستعادة» هتوصله على Outlook كمان. الموظف بيخرج من كل الأجهزة، وأول ما يدخل بالمؤقتة بيظهرله شباك يختار فيه كلمة جديدة.
- **موظف نسي:** من صفحة الدخول ← «نسيت كلمة المرور؟» ← يكتب اسم المستخدم ← يوصله لينك على Outlook.
- **أول مرة بيوصل الإيميل غالباً على Junk في Outlook.** قول للموظفين يعلّموه **Not junk**.

- **تغيير اسم المستخدم (للأدمن):** الموظفين ← تعديل ← الصلاحيات ← **تغيير اسم المستخدم**. بتكتب الإيميل الجديد (مثلاً Outlook)، والسيستم بينقل كل بياناته (الحضور والطلبات والأرصدة والرواتب والفريق التابع ليه) ويغيّر اسم الدخول. كلمة المرور بتفضل زي ما هي. لو غيّرت اسمك إنت، هتخرج وتدخل بالاسم الجديد.
- لو اسم المستخدم نفسه إيميل حقيقي (زي `almaster.hr@outlook.com`) ومفيش إيميل استعادة، لينك «نسيت كلمة المرور» بيروح عليه هو.

## تحديث الكود بعدين
Deploy ← **Manage deployments** ← ✏️ ← Version: **New version** ← Deploy. الرابط مش بيتغير.

## لو المفتاح اتسرّب
Google Cloud Console ← IAM & Admin ← **Service accounts** ← `firebase-adminsdk-…` ← **Keys** ← امسح المفتاح، واعمل واحد جديد من الخطوة 1 وحطه في Script Properties.

## مشاكل شائعة
| الرسالة | الحل |
|---|---|
| «الخدمة وصلت بس مفتاح Firebase مش شغال» | `SERVICE_ACCOUNT` ناقص أو متنسخ ناقص. انسخ ملف الـ JSON كله من أول `{` لآخر `}`. |
| «تعذّر الوصول لخدمة كلمات المرور» | الرابط غلط أو Who has access مش Anyone. |
| «الموظف ملوش إيميل استعادة» | ضيف له إيميل Outlook من ملفه. |
| «ملوش حساب دخول» | الموظف موجود في السيستم بس مش موجود في Firebase Authentication. |
